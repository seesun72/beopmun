# 내 마음의 법문 — 폰 앱(홈 화면 웹앱)

정전·대종경 원문으로 오늘 마음에 와닿는 법문을 고르고, 감상과 해석을 적고, 출처를 알아맞추는 앱입니다.
갤럭시와 아이폰 모두 **홈 화면에 추가**하면 앱처럼 아이콘으로 열립니다. Claude 로그인은 필요 없습니다.

## 들어 있는 파일
| 파일 | 하는 일 |
| --- | --- |
| index.html | 앱 화면 전체 |
| jeongjeon.js · daejonggyeong.js | 정전 300구절 · 대종경 547장 원문 |
| config.js | '함께 읽기' 서버(Firebase) 설정. 비워 두면 함께 읽기만 꺼집니다 |
| manifest.webmanifest · icons/ | 홈 화면 아이콘과 앱 이름 |
| sw.js | 한 번 연 뒤에는 인터넷이 없어도 열리게 함 |
| firestore.rules | 함께 읽기 서버의 보안 규칙 |

## 1단계 — 인터넷 주소에 올리기 (무료)
아래 둘 중 하나를 고릅니다. 둘 다 https 주소가 생기며, 그 주소가 곧 앱 주소입니다.

- **Netlify Drop**: app.netlify.com/drop 에 접속해 이 폴더 전체를 끌어다 놓습니다. 계정을 만들면 주소가 유지됩니다.
- **GitHub Pages**: 새 저장소에 이 폴더의 파일을 올리고, 저장소 Settings → Pages 에서 main 브랜치를 켭니다.

## 2단계 — 폰에 설치하기
- **아이폰**: Safari로 앱 주소를 엽니다 → 아래 공유 단추 → '홈 화면에 추가'.
- **갤럭시**: Chrome 또는 삼성 인터넷으로 앱 주소를 엽니다 → 메뉴(⋮ 또는 ≡) → '홈 화면에 추가' 또는 '앱 설치'.

## 3단계 — '함께 읽기' 켜기

> 2026-11-14에 프로젝트 **won-beopmun**으로 1~4번을 마쳤고 config.js에 값을 넣어 두었습니다. 남은 일은 앱 주소를 '승인된 도메인'에 추가하는 것뿐입니다(아래 6번).

### 처음부터 다시 할 때
다른 사람이 오늘 고른 법문과 감상을 이름 없이 실시간으로 보려면 무료 Firebase 프로젝트가 필요합니다.

1. console.firebase.google.com 에서 새 프로젝트를 만듭니다 (애널리틱스는 꺼도 됩니다).
2. **Authentication → 로그인 방법 → 익명**을 사용 설정합니다. 이용자는 로그인 화면 없이 자동으로 이름 없는 번호를 받습니다.
3. **Firestore Database**를 만들고(위치: asia-northeast3 서울), **규칙** 탭에 `firestore.rules` 내용을 그대로 붙여 넣고 게시합니다.
4. **프로젝트 설정 → 내 앱 → 웹 앱 추가**를 누르면 나오는 `apiKey · authDomain · projectId · appId` 값을 `config.js`에 붙여 넣습니다.
5. 1단계를 다시 해서 바뀐 config.js를 올립니다.
6. 앱 주소가 생기면 **Authentication → 설정 → 승인된 도메인**에 그 주소(예: beopmun.netlify.app)를 추가합니다. 빠뜨리면 함께 읽기가 연결되지 않습니다.

## 알아 두실 점
- **개인 기록**(고른 법문, 감상)은 각자의 폰에만 저장됩니다. 폰을 바꾸기 전에 '마음 돌아보기 → 기록 내보내기'로 파일을 받아 두고 새 폰에서 '불러오기' 하세요.
- **함께 읽기**는 한 사람이 하루에 글 하나만 올리며, 화면에 이름은 나오지 않습니다. 부적절한 글은 Firebase 콘솔 → Firestore → feed 에서 해당 문서를 지우면 내려갑니다.
- 익명 방식이라 마음먹고 여러 번 새로 접속하면 글을 여러 개 올릴 수는 있습니다. 교당 규모에서는 문제가 될 일이 드물지만, 필요해지면 로그인 방식으로 바꿀 수 있습니다.
- 원문을 고치려면 jeongjeon.js · daejonggyeong.js 를 고친 뒤, sw.js 맨 위 VERSION 글자를 바꾸고 다시 올리면 모든 폰에 새 원문이 퍼집니다.
